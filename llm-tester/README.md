# LLM Prompt & Model Testing Tool

Универсальный инструмент для тестирования промтов и моделей LLM с использованием подхода "LLM-as-a-Judge".

## Возможности

- **Поддержка множества провайдеров**: Google, OpenRouter, GigaChat, Anthropic, OpenAI и другие
- **Pool/Fallback режим**: автоматическое переключение между провайдерами при ошибках
- **Создание и управление тестами**: настройка промтов, входных данных, критериев оценки
- **Оценка результатов**: время ответа, стоимость, оценка судьи, сравнение моделей
- **Веб-интерфейс**: удобная настройка провайдеров, создание тестов, просмотр результатов
- **Экспорт результатов**: CSV/Excel форматы
- **История запусков**: хранение последних N результатов

## Быстрый старт

### Через Docker Compose

```bash
docker-compose up -d
```

Приложение будет доступно по адресу: http://localhost:8000

### Локальный запуск

#### Бэкенд
```bash
cd backend
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate на Windows
pip install -r requirements.txt
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```

#### Фронтенд
```bash
cd frontend
npm install
npm run dev
```

## Настройка провайдеров

1. Откройте веб-интерфейс
2. Перейдите в раздел "Провайдеры"
3. Добавьте API-ключи для нужных провайдеров
4. Настройте порядок приоритета для fallback режима

## Создание теста

1. Создайте задачу (Task) с описанием сценария
2. Добавьте тест-кейсы с входными данными и промтом
3. Настройте промт судьи для оценки результатов
4. Запустите тест и просмотрите результаты

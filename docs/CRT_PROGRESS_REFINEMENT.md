# Подключения, прогресс и ответы — 2026-10-02

Основание: четыре замечания владельца. Контракт и UX до реализации:

- ModelRoute.capabilities.base_url — явный адрес API ЦРТ (HTTP/HTTPS, сервер, порт, путь). Нет встроенного адреса/fallback. Каталог и генерация используют его; snapshot сохраняет адрес. HTTP требует согласия, HTTPS нет. URL без credentials/query/fragment; redirects запрещены. Старое подключение без адреса требует редактирования; старые snapshots неизменны, повтор без адреса отклоняется до вызова.
- До вызова RunItem становится running, создаётся Attempt с sequence/start time. HTTP-попытки показываются отдельно от повторов строки. Процент означает обработанные строки, ошибки считаются отдельно. Активная строка — spinner, ожидание — часы, успех/ошибка — значки с текстом. Закреплённая панель результата видна при прокрутке; история обновляется без открытия запуска. Общая полоса активных запусков со ссылками видна во всех разделах.
- Drawer показывает текст с переносами, исходный JSON отдельно. ЦРТ: явно размеченные think/thought/analysis отделяются от финального ответа, внешние fences снимаются; исходный текст сохраняется. Произвольные слова thought/xml и escape sequences не удаляются. Старые данные не переписываются. Только reasoning — отсутствие финального ответа.
- Invalid JSON/envelope/transport — разные безопасные коды, без raw bodies. Таймаут поясняет лимит; изменение подключения влияет на новые запуски, не на snapshot повтора.

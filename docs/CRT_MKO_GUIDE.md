# ЦРТ МКО и YAML-промпты

## Подключение

На странице «Модели» выберите «ЦРТ МКО — без авторизации». Укажите полный адрес API вашего сервера: протокол, сервер, порт и путь, например `https://mko.example.org:8443/api/v1`. Для HTTP подтвердите передачу без шифрования, затем нажмите «Обновить список». Выберите модель, задайте максимальное ожидание и сохраните подключение. Встроенного адреса нет; каталог и генерация используют заданный адрес. HTTPS не требует согласия HTTP. Адрес с логином, паролем, query или fragment не принимается.

У существующего подключения нажмите «Изменить» и заполните адрес. Изменение влияет на новые запуски. Старый snapshot без адреса не переписывается; его повтор отклоняется с объяснением — создайте новый запуск. Снимок нового запуска фиксирует адрес и timeout, поэтому последующее редактирование подключения не меняет повтор старого запуска.

Поддерживается текстовый engine stc_llama, без streaming. Лимит выходных токенов для этого сервиса пока не гарантируется. Отмена не прерывает уже отправленный запрос: после него новые строки не запускаются. Подключение можно использовать для генерации и отдельно как судью; способность модели соблюдать формат оценок проверяется каждым запуском.

Разрешённый владельцем один технический запрос уже выполнен: gemma3:4b вернула OK. Это подтверждает контракт API, но не качество оценки произвольного датасета. Автоматические тесты используют подставные ответы, не сервер.

## YAML

«Эксперименты → Настройки → Инструкция → Загрузить YAML-промпт» заполняет редактор без автоматического сохранения. Переносятся name и текст template либо prompt/instructions/examples. Настройки engine, модели, схемы ответа и уведомлений не переносятся; интерфейс перечисляет пропущенные поля.

Проверьте текст, при необходимости добавьте подстановку {{text}}, затем сохраните инструкцию. Файл должен быть UTF-8, до 256 KiB, без YAML anchors/aliases и специальных тегов. Исходные файлы не меняются.


## Ожидание и формат ответа

В общей полосе активных запусков есть переход к конкретной генерации/оценке. В результатах отображаются процент обработанных строк, ошибки, текущая строка, номер попытки и время ожидания. Попытка строки и HTTP-повтор различаются; отмена не гарантирует остановку уже отправленного серверу запроса.

Ошибка timeout означает, что ответ не завершился в заданное время. Увеличьте «Максимальное ожидание» подключения (до 600 секунд) и создайте новый запуск. Это не гарантирует ответ: при повторяющихся таймаутах нужна проверка состояния сервера/модели. Invalid JSON и ошибка сервиса внутри HTTP 200 показываются отдельно без публикации raw HTTP body.

Явные блоки think/thought/analysis отделяются от финального текста, исходный ответ сохраняется. Только служебные блоки без финального ответа считаются пустым ответом. В drawer основной текст показан с переносами; исходный ответ и JSON доступны в раскрываемом блоке. Старые результаты показываются удобнее без перезаписи БД; их исторические оценки не меняются.

# ЦРТ МКО и YAML-промпты

## Подключение

На странице «Модели» выберите «ЦРТ МКО — без авторизации». Каталог загружается с сервера; выберите модель, задайте ожидание и сохраните подключение. Ключ не требуется. Подтверждение HTTP обязательно: тексты передаются без шифрования на http://super-project-work.ru:8001. Не отправляйте чувствительные данные без разрешения их владельца.

Поддерживается текстовый engine stc_llama, без streaming. Лимит выходных токенов для этого сервиса пока не гарантируется. Отмена не прерывает уже отправленный запрос: после него новые строки не запускаются. Подключение можно использовать для генерации и отдельно как судью; способность модели соблюдать формат оценок проверяется каждым запуском.

Разрешённый владельцем один технический запрос уже выполнен: gemma3:4b вернула OK. Это подтверждает контракт API, но не качество оценки произвольного датасета. Автоматические тесты используют подставные ответы, не сервер.

## YAML

«Эксперименты → Настройки → Инструкция → Загрузить YAML-промпт» заполняет редактор без автоматического сохранения. Переносятся name и текст template либо prompt/instructions/examples. Настройки engine, модели, схемы ответа и уведомлений не переносятся; интерфейс перечисляет пропущенные поля.

Проверьте текст, при необходимости добавьте подстановку {{text}}, затем сохраните инструкцию. Файл должен быть UTF-8, до 256 KiB, без YAML anchors/aliases и специальных тегов. Исходные файлы не меняются.

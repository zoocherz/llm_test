# Бесплатные API-провайдеры с текстовыми моделями для роли "Судьи" (Judge/Evaluator)

> **Дата актуализации:** 08.09.2026
> **Назначение:** Оценка работы маленьких настольных моделей (например, при аннотации телефонных звонков, проверке промптов, LLM-as-a-Judge)
> **Критерий отбора:** Высокое качество рассуждений (reasoning), большой контекст, поддержка структурированного вывода, наличие бесплатного уровня

---

## Ключевые требования к модели-судье

Для задачи оценки работы маленькой модели (например, аннотация телефонного звонка) критически важны:

1. **Сильные reasoning-способности** — модель должна понимать нюансы, контекст, скрытые смыслы
2. **Большой контекстный окно** — транскрипты звонков могут быть длинными (10–60 минут = 5k–30k токенов)
3. **Следование инструкциям** — чёткое соблюдение критериев оценки, структурированный вывод (JSON)
4. **Низкая температура галлюцинаций** — модель должна давать стабильные, воспроизводимые оценки
5. **Поддержка русского языка** — для локальных задач (опционально, но желательно)

## Топ-3 модели для роли судьи (рекомендации)

### 🥇 1. DeepSeek R1 (через DeepSeek API или OpenRouter)
**Почему:** Специализированная reasoning-модель, обученная на задачах сложного анализа. Отлично подходит для оценки работы других моделей, выявления ошибок, проверки соответствия критериям.  
**Минус:** После приветственного гранта всё равно платная (но очень дешёвая).

### 🥈 2. Qwen3-Max (через Qwen Cloud / Alibaba DashScope)
**Почему:** Одна из лучших reasoning-моделей на рынке. Превосходит многие аналоги в задачах оценки и анализа. Огромный контекст.  
**Минус:** Приветственный грант ограничен 90 днями.

### 🥉 3. Gemini 2.5 Pro (через Google AI Studio)
**Почему:** Постоянный бесплатный тариф с высокими лимитами. Отличные reasoning-способности. Огромный контекст (1M токенов).  
**Минус:** Может быть медленнее специализированных reasoning-моделей.

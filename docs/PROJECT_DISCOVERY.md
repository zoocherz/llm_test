# LLM Evaluation Workbench — первичная спецификация

## Назначение

Локальный сервис для воспроизводимого выбора модели и промпта для произвольной LLM-задачи. Он запускает маршруты `провайдер + модель` на датасете, сохраняет ответы, latency, usage, стоимость, ошибки и оценки, после чего позволяет сравнить и экспортировать результат.

Первые шаблоны: аннотация телефонных звонков и распознавание типа и состава продуктов по фотографии. Первый сквозной сценарий — фото продуктов.

## Принятые решения

| Область | Решение |
| --- | --- |
| Пользователь | Один пользователь на локальной Windows-машине |
| Цель | Выбрать подходящую LLM-модель |
| Стек MVP | FastAPI + Vue + SQLite |
| Модальности | Текст и изображения |
| Форматы | CSV и JSONL |
| Ответ target-модели | Свободный текст; JSON Schema — расширение |
| Оценка | Настраиваемая; LLM-Judge для каждой строки |
| Первые провайдеры | Google, OpenRouter, GigaChat |
| Медиа | Локальное хранение в папке проекта |

## Политика fallback

В сравнительном эксперименте fallback выключен. Разрешены ограниченные повторы того же маршрута при timeout, 429 и 5xx. Модель нельзя незаметно заменить другой: это исказит результат.

Отдельный режим пула доступности использует явный упорядоченный список совместимых маршрутов. Смена маршрута, причина и все попытки сохраняются и помечаются как fallback.

## Открытые данные для старта

Нужны 5–10 реальных или открытых фотографий продуктов для smoke-датасета. Для каждой строки достаточно уникального id, изображения и короткой пользовательской инструкции; эталонная разметка необязательна.
